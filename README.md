# 🇮🇳 2002-SIR Data India
### *National Database & Regional State Portals Hub*

A premium, highly interactive, and state-of-the-art digital directory designed to serve as a beautiful central hub for regional Electoral Rolls and **State Information Resource (SIR)** database portals (such as the active: **Telangana** link). 

---

## 🎯 Project Purpose & Background
The **2002-SIR Data India Portal** was built to address the challenge of decentralized, fragmented government database directories. It serves as a unified search gateway for commom people, researchers, data scientists, and administrators looking for historic administrative and electoral archives from the year **2002**.

By including **all 28 States and 8 Union Territories** of India under a single digital console, the portal makes it effortless to locate regional databases. It acts as a primary bridge to individual state scrapers, digital lists, and local scrap portals.

By clicking the **Open** button in the **Active** cards the user can view the full database for that state and search the information about the person's details in the last **Special Intensive Revision (SIR)** role which was done in the year **2002-2003**.
